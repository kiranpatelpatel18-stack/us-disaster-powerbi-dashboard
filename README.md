# US Disaster Declarations Analytics Dashboard (Power BI)

## 📊 Project Overview
This project analyzes FEMA disaster declarations data using Power BI to identify geographic and temporal patterns, incident types, program support, and disaster duration trends.

It also includes What-If scenario modeling to estimate resource needs under changing disaster frequency.

## 🎯 Key Features
- Disaster frequency trends over time
- State and county geographic analysis
- Incident type and program insights
- Disaster duration & declaration timing analysis
- What-If scenario simulation

## 🧱 Data Modeling
Star schema with:
- FactDisaster table
- State, County, Incident, Program, Date dimensions

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- FEMA Disaster Dataset
